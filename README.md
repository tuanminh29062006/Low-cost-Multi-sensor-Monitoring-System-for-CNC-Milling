# Low-Cost Multi-Sensor Monitoring System for CNC Milling

[![Field](https://img.shields.io/badge/Domain-Smart%20Manufacturing%20%26%20IoT-green.svg)](#)
[![Affiliation](https://img.shields.io/badge/Institution-HCMUT--VNUHCM-blue.svg)](#)

A modular, real-time Tool Condition Monitoring (TCM) framework for CNC milling operations utilizing multi-sensor data fusion, edge acquisition, and IoT telemetry.

---

In modern machining, cutting tool degradation, chipping, and wear directly impact surface roughness, dimensional accuracy, and operating downtime. High-end industrial monitoring solutions often impose prohibitive hardware costs. 

This project explores an accessible, industrial-grade monitoring platform that synchronously collects multi-physical signals—cutting force, vibration, surface temperature, and environmental sound—to deliver real-time process visibility, tool health diagnostics, and predictive maintenance capabilities.
